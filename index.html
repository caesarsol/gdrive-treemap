What fills your Google Drive?

A treemap of every file you own in Drive, trash included: each rectangle is as large as the space the file takes from your storage quota.

Everything runs in this page. It asks Google for read-only access to file names and sizes (never their contents), and nothing leaves your browser.

How to get a client ID
  1. In Google Cloud Console, create or pick a project.
  2. APIs & Services → Library: enable the Google Drive API.
  3. OAuth consent screen: External (or Internal for Workspace); add the scope drive.metadata.readonly; in Testing, add yourself as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application; add this page's origin under Authorized JavaScript origins. No redirect URI is needed.
